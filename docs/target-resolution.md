# 目标分辨率选择

上传区提供 1080p、2K（1440p）、4K 选择，配置统一放在 `src/config/pricing.ts`。免费试用开放 1080p，高分辨率标注付费；切回免费模式会恢复到 1080p。

上传后的尺寸和额度来自服务端 metadata 响应，展示原始尺寸与预计输出尺寸。横屏、竖屏及其他比例都保持原比例，不拉伸或强制裁成 16:9。例如 720×1280 竖屏输出为 1080×1920，800×600 输出为 1440×1080。

新任务传 `resolution`，服务端重新探测元数据并计算实际倍率，忽略请求体伪造的倍率、像素尺寸和扣费额度。目标低于原片或超过模型最大放大范围时，在提交前显示明确错误。原有的倍率 API 请求仍可使用，以兼容旧客户端。

`VideoJob.scale` 改为浮点数，迁移保留原有任务、结果、归因关联和轮询租约；数据库校验范围为 1 至 4。付费报价和结果验证使用同一个服务端倍率。结果页展示真实像素尺寸，不再把倍率当成产品选项描述。

免费视频仍只处理开头五秒、每账号一次、强制水印。付费输出按预计分辨率折算标准额度，详见[计费规则](payments.md)。
